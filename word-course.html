📌 Alignment: Left, Center, Right અને Justify લખાણ.
📌 Styles: Heading 1, 2 વડે પુસ્તક જેવો વ્યાવસાયિક લુક.

Lesson 1
ઓટો-ટાઈપિંગ પ્રેક્ટિસ ટ્રીક (=rand)
હાથેથી લાંબુ ટાઈપ કર્યા વગર પ્રેક્ટિસ માટે ૧ સેકન્ડમાં તૈયાર ફકરા લાવવા.
⌨️ Word Magic Code:
લખો: =rand(3,4) અને Enter આપો.
➔ તરત જ ૩ ફકરા (૪-૪ વાક્યોવાળા) સ્ક્રીન પર આવી જશે!
📍 કમાન્ડ: =rand(ફકરા, વાક્યો)
Instant Code

=rand(3,4)

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. નવા કોરા પેજ પર સીધું =rand(3,4) ટાઈપ કરો.
  2. કીબોર્ડ પરથી Enter દબાવો. પ્રેક્ટિસ માટે રેડી-મેડ ટેક્સ્ટ મળી જશે.
Lesson 2
ગુજરાતી-અંગ્રેજી ટાઈપિંગ & સ્પેલચેક
શ્રુતિ/ઇન્ડિક ફોન્ટ સ્વિચિંગ અને લાલ લીટીવાળી જોડણી ભૂલો સુધારવી.
• ગુજરાતી: Shruti / Gujarati Indic IME (Win + Space)
• અંગ્રેજી: Times New Roman / Calibri (12pt)
• સ્પેલિંગ ભૂલ: Skool ➔ School (F7)
📍 શોર્ટકટ: Win + Space (ભાષા) | F7 (સ્પેલિંગ)
Shortcut

Win + Space (Switch Lang) | F7 (Spelling Check)

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ગુજરાતી ટાઈપિંગ માટે કીબોર્ડ પરથી Win + Space દબાવો.
  2. જોડણી સુધારવા માટે F7 દબાવો અથવા શબ્દ પર રાઈટ-ક્લિક કરી સાચો શબ્દ પસંદ કરો.

Lesson 4
ફોર્મેટ પેઇન્ટર (Format Painter - જાદુઈ બ્રશ)
એક લખાણની ડિઝાઇન, કલર અને સાઇઝ અન્ય લખાણ પર ૧ ક્લિકમાં લાગુ કરવી.

  2. જેના પર તે ડિઝાઇન લગાવવી હોય તેને સિલેક્ટ કરી Ctrl + Shift + V આપો.
Lesson 5
પેરેગ્રાફ અલાઈનમેન્ટ (Justify)
પુસ્તકો અને અખબારોની જેમ બંને બાજુથી લખાણ એકસરખી લાઈનમાં રાખવું.
Justified Text: શિક્ષણ એ વ્યક્તિના જીવનમાં પરિવર્તન લાવનાર સૌથી શક્તિશાળી સાધન છે, જેનાથી ભવિષ્ય ઉજ્જવળ બને છે.
📍 શોર્ટકટ: Ctrl + J (Justify)
Shortcut

Ctrl + L (Left) | Ctrl + E (Center) | Ctrl + J (Justify)

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. આખો ફકરો સિલેક્ટ કરો.
  2. કીબોર્ડ પરથી Ctrl + J દબાવો. ડાબી-જમણી બંને કિનારીઓ સરખી થશે.

બીજી વ્યક્તિએ ડોક્યુમેન્ટમાં કરેલા ફેરફારો અને ભૂલો લાલ કલરમાં પકડવા.
આ વર્ષે શાળા સોમવારે મંગળવારે ખુલશે. (Tracked)
📍 શોર્ટકટ: Ctrl + Shift + E
Shortcut

Review -> Track Changes (Toggle ON)

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. Review ટેબમાં જઈ Track Changes ચાલુ કરો.
  2. હવે કોઈપણ નવો શબ્દ લખાશે કે ડીલીટ થશે તે લાલ રંગના માર્કિંગ સાથે રેકોર્ડ થશે.

Advanced 6
ડોક્યુમેન્ટ પ્રોટેક્શન (Password Lock)
કોઈપણ વ્યક્તિ તમારી મંજૂરી વગર ફાઈલ ખોલી કે બદલી ન શકે તેવો લોક.
🔒 Password Protected: Enter password to open file [ ***** ]
📍 મેનુ: File -> Info -> Protect Document
Security Action

File -> Info -> Encrypt with Password

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. File મેનુમાં Info પર જાઓ.
  2. Protect Document -> Encrypt with Password પસંદ કરી મજબૂત પાસવર્ડ સેટ કરો.
Advanced 7
ગણિતના સમીકરણો (Equation Editor)
ગણિતના અઘરા સૂત્રો (અપૂર્ણાંક, વર્ગમૂળ, ઘાત) સચોટ ટાઈપ કરવા.
📐 A = πr² | x = (-b ± √(b² - 4ac)) / 2a
📍 શોર્ટકટ: Alt + = (Insert Equation)
Shortcut

Press 'Alt + =' to type professional math symbols

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. જ્યાં સૂત્ર લખવું હોય ત્યાં Alt + = દબાવો.
  2. ઉપર Equation ટૂલબારમાંથી Fraction, Radical કે Matrix પસંદ કરી સૂત્ર ટાઈપ કરો.

  2. જનરેટ થયેલ પત્ર સીધો કોપી કરી MS Word માં પેસ્ટ કરી પ્રિન્ટ લો.
Advanced 9
ઓટો-સેવ & રિકવરી (AutoRecover)
લાઈટ જતી રહે કે અચાનક કમ્પ્યુટર બંધ થાય તો અનસેવ્ડ ફાઈલ પાછી મેળવવી.
⚡ AutoRecover: Save every 1 minute | Recover Unsaved Documents
📍 સેટિંગ: File -> Options -> Save
Recovery Action

File -> Info -> Manage Document -> Recover Unsaved Documents

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. File -> Options -> Save માં જઈ "Save AutoRecover information every" ને 1 minute કરી દો.
  2. જો ફાઇલ સેવ કર્યા વગર બંધ થાય, તો File -> Info -> Manage Document માંથી પાછી મેળવી શકાય છે.
