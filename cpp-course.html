C & C++ Overview & Benefits
પ્રોગ્રામિંગ જગતની માતા સમાન ભાષાઓ અને કોડિંગની શરૂઆતનો મજબૂત પાયો.
🌱 C અને C++ શું છે? (Architecture)
C એ તમામ આધુનિક પ્રોગ્રામિંગ ભાષાઓનો પાયો છે, જ્યારે C++ એ તેમાં Object-Oriented Programming (OOPs) ફીચર્સ ઉમેરેલી અદભુત ભાષા છે.
📌 #include <iostream>: ઇનપુટ/આઉટપુટ લાઈબ્રેરી.
📌 main(): પ્રોગ્રામ executionનું મુખ્ય કેન્દ્ર.
📌 cout / printf: સ્ક્રીન પર પરિણામ પ્રિન્ટ કરવું.
📌 Variables: int, float, char ડેટા ટાઈપ્સ.

Level 1: 12 Foundation Lessons
બેરિએબલ્સ, ડેટા ટાઇપ્સ, શરતી વિધાનો (if-else), સ્વિચ કેસ અને લૂપ્સ.
Lesson 1
પ્રથમ પ્રોગ્રામ (Hello World in C++)
સી પ્લસ પ્લસનું સ્ટ્રક્ચર સમજી સ્ક્રીન પર લખાણ પ્રિન્ટ કરવાનો મૂળભૂત પ્રોગ્રામ.
#include <iostream>
using namespace std;
int main() {
  cout << "Hello World";
  return 0;
}
📍 સિન્ટેક્સ: cout << "..."
Syntax

cout << "Hello World" << endl;

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. હેડર ફાઇલ ઇન્ક્લુડ કરો.
  2. main() ફંક્શનમાં cout દ્વારા આઉટપુટ લાવો.
Lesson 2
વેરિએબલ્સ & ડેટા ટાઇપ્સ (Variables & Types)
પૂર્ણાંક (int), દશાંશ (float) અને કેરેક્ટર (char) કિંમતો મેમરીમાં સાચવવી.
int age = 16;
float percentage = 92.5;
char grade = 'A';
📍 ડેટા ટાઇપ: int, float, char, double
Variables

int rollNo = 101; float marks = 85.5;

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. યોગ્ય ડેટા ટાઇપ સાથે વેરિએબલ ડિક્લેર કરો.
Lesson 3
કીબોર્ડથી ઇનપુટ લેવું (cin / scanf)
યુઝર પાસેથી રન-ટાઇમ પર ડેટા મેળવી પ્રોસેસ કરવો.
int marks;
cout << "માર્ક્સ નાખો: ";
cin >> marks;
📍 સિન્ટેક્સ: cin >> variable
Input Command

cin >> x >> y;

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. cin દ્વારા યુઝર પાસેથી કિંમત ઇનપુટ કરાવો.
Lesson 4
શરતી વિધાનો (if-else Conditions)
જો માર્ક્સ ૩૫ થી વધુ હોય તો પાસ, અન્યથા ફેલ નક્કી કરવું.
if (marks >= 35) {
  cout << "Pass";
} else {
  cout << "Fail";
}
📍 કીવર્ડ્સ: if, else
Condition

if (score > 80) { cout << "A Grade"; }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. if-else બ્લોક દ્વારા લોજિક લખો.
Lesson 5
નેસ્ટેડ ઇફ-એલ્સ (Nested if-else / Grades)
એક કરતાં વધુ શરતો (A, B, C, D ગ્રેડ) ચકાસવા માટે મલ્ટીપલ કન્ડિશન્સ.
if (marks >= 90) cout << "A";
else if (marks >= 75) cout << "B";
else cout << "C";
📍 સિન્ટેક્સ: if ... else if ... else
Nested Condition

else if (condition) { ... }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. else if નો ઉપયોગ કરી ગ્રેડ સિસ્ટમ બનાવો.
Lesson 6
સ્વિચ સ્ટેટમેન્ટ (switch-case)
વારંવાર else-if વાપરવાના બદલે ચોક્કસ વિકલ્પો માટે switch વાપરવું.
switch(day) {
  case 1: cout << "સોમવાર"; break;
  default: cout << "અન્ય દિવસ";
}
📍 કીવર્ડ્સ: switch, case, break, default
Switch Statement

switch(ch) { case 'a': ... break; }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. કેસ અને બ્રેક સ્ટેટમેન્ટ સાથે સ્વિચ રચના બનાવો.
Lesson 7
ફોર લૂપ (for loop)
૧ થી ૧૦૦ નંબરો પ્રિન્ટ કરવા કે પુનરાવર્તિત કામ માટે ફોર લૂપ.
for (int i = 1; i <= 10; i++) {
  cout << i << " ";
}
📍 લૂપ સિન્ટેક્સ: for (init; condition; increment)
For Loop

for (int i=0; i<5; i++) { ... }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ઇનિશિયલાઇઝેશન, કન્ડિશન અને ઇન્ક્રિમેન્ટ સેટ કરો.
Lesson 8
વ્હાઈલ અને ડુ-વ્હાઈલ લૂપ (while & do-while)
શરત સાચી હોય ત્યાં સુધી લૂપ ચલાવવા માટે while અને ઓછામાં ઓછી ૧ વાર ચલાવવા do-while.
int i = 1;
while (i <= 5) {
  cout << i;
  i++;
}
📍 લૂપ કીવર્ડ્સ: while, do-while
While Loop

while (x > 0) { x--; }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. વ્હાઈલ લૂપ દ્વારા કન્ડિશન ચેક કરો.
Lesson 9
એરે (1D Arrays)
એક જ વેરિએબલમાં ઘણા બધા નંબરો (દા.ત. ૫ વિદ્યાર્થીઓના માર્ક્સ) સ્ટોર કરવા.
int marks[5] = {85, 90, 78, 92, 88};
cout << marks[0]; // Outputs 85
📍 એરે સિન્ટેક્સ: data_type array_name[size]
Array

int arr[10]; arr[0] = 5;

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. સાઇઝ સાથે એરે ડિક્લેર કરી ઇન્ડેક્સથી વેલ્યુ મેળવો.
Lesson 10
સ્ટ્રિંગ્સ (Strings & Character Arrays)
શબ્દો અને નામ (દા.ત. "Rajesh") સ્ટોર અને પ્રિન્ટ કરવા.
string name;
cout << "નામ લખો: ";
cin >> name;
cout << "નમસ્તે " << name;
📍 ડેટા ટાઇપ: string (C++) / char[] (C)
String

string fullName = "Amit Patel";

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. string હેડર ઇન્ક્લુડ કરી નામ પ્રિન્ટ કરો.
Lesson 11
યુઝર ડિફાઇન્ડ ફંક્શન્સ (Functions)
કોડને મોડ્યુલર બનાવવા અને રીયુઝ કરવા માટે કસ્ટમ ફંક્શન બનાવવા.
int add(int a, int b) {
  return a + b;
}
// Call: add(5, 10);
📍 ફંક્શન: return_type name(parameters)
Function

void display() { cout << "Hello"; }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ફંક્શન ડિફાઇન કરી main() માં કોલ કરો.
Lesson 12
પોઇન્ટર્સ (Pointers - મેમરી એડ્રેસ)
વેરિએબલનું મેમરી એડ્રેસ સ્ટોર કરનાર શક્તિશાળી પોઇન્ટર કન્સેપ્ટ.
int x = 10;
int *ptr = &x;
cout << *ptr; // Outputs 10
📍 ઓપરેટર્સ: & (Address) | * (Value at address)
Pointer

int *p = &var;

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. એડ્રેસ ઓપરેટર (&) દ્વારા પોઇન્ટર ડિક્લેર કરો.
Level 2: 9 Advanced & OOPs Modules
Classes & Objects, Inheritance, Polymorphism, File Handling અને AI C++ Prompting.
Advanced 1
ક્લાસ અને ઓબ્જેક્ટ્સ (Classes & Objects - OOPs)
ઓબ્જેક્ટ ઓરિએન્ટેડ પ્રોગ્રામિંગનો પાયો; ક્લાસ બનાવી તેના ઓબ્જેક્ટ્સ ડિક્લેર કરવા.
class Student {
  public:
    string name;
    void display() { cout << name; }
};
// Object: Student s1;
📍 કીવર્ડ: class, public, private
OOPs Class

class Car { public: string brand; };

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ક્લાસ બનાવી તેના મેમ્બર ફંક્શન્સ કોલ કરો.
Advanced 2
કન્સ્ટ્રક્ટર અને ડિસ્ટ્રક્ટર (Constructor & Destructor)
ઓબ્જેક્ટ બનતી વખતે ઓટોમેટિક કોલ થતું સ્પેશિયલ ફંક્શન (Constructor).
class Car {
  public:
    Car() { cout << "Object Created!"; }
};
📍 કન્સેપ્ટ: Default & Parameterized Constructor
Constructor

Student() { marks = 0; }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ક્લાસના નામ જેવું જ કન્સ્ટ્રક્ટર ફંક્શન બનાવો.
Advanced 3
ઇન્હેરીટન્સ (Inheritance - વારસામાં મળતા ગુણો)
એક ક્લાસના ફીચર્સ બીજા ક્લાસમાં વારસામાં મેળવવા (Parent & Child Class).
class Animal {
  public: void eat() { cout << "Eating..."; }
};
class Dog : public Animal { ... };
📍 સિન્ટેક્સ: class Child : public Parent
Inheritance

class Programmer : public Employee { ... };

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ચાઇલ્ડ ક્લાસ બનાવી પેરેન્ટના ફંક્શન્સ યુઝ કરો.
Advanced 4
પોલિમોર્ફિઝમ (Polymorphism - અનેક સ્વરૂપો)
એ જ નામનું ફંક્શન અલગ-અલગ કામ કરે (Function Overloading / Overriding).
void sum(int a, int b) { ... }
void sum(double a, double b) { ... }
📍 કન્સેપ્ટ: Compile-time & Run-time Polymorphism
Polymorphism

virtual void draw() { ... }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ઓવરલોડિંગ દ્વારા સમાન નામની મેથડ્સ બનાવો.
Advanced 5
એનકેપ્સ્યુલેશન (Encapsulation & Getters/Setters)
પ્રાઇવેટ ડેટાને સુરક્ષિત રાખી પબ્લિક ગેટર-સેટર ફંક્શન્સ દ્વારા એક્સેસ આપવો.
class Account {
  private: int balance;
  public: void setBal(int b) { balance = b; }
};
📍 કન્સેપ્ટ: Data Hiding (Private + Public)
Encapsulation

int getBalance() { return balance; }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. પ્રાઇવેટ વેરિએબલ ડિક્લેર કરી ગેટર-સેટર બનાવો.
Advanced 6
ફાઇલ હેન્ડલિંગ (File Handling in C++)
કમ્પ્યુટરની હાર્ડડિસ્કમાં ટેક્સ્ટ ફાઇલ બનાવી તેમાં ડેટા સેવ કરવો અને વાંચવો.
ofstream outFile("data.txt");
outFile << "Hello File!";
outFile.close();
📍 લાઈબ્રેરી: <fstream>, ofstream, ifstream
File I/O

ifstream inFile("data.txt"); inFile >> text;

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ofstream દ્વારા ફાઇલમાં લખાણ સેવ કરો.
Advanced 7
એક્સેપ્શન હેન્ડલિંગ (Exception Handling - try/catch)
પ્રોગ્રામ રન થતી વખતે અચાનક આવતી એરર્સ (દા.ત. Divide by Zero) ને હેન્ડલ કરવી.
try {
  throw 505;
} catch (int e) {
  cout << "Error Code: " << e;
}
📍 કીવર્ડ્સ: try, catch, throw
Exception

try { ... } catch(...) { ... }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. try અને catch બ્લોક દ્વારા ક્રેશ થતો કોડ બચાવો.
Advanced 8
સ્ટ્રક્ચર્સ (Structures in C / C++)
અલગ-અલગ ડેટા ટાઇપ્સ (નામ, રોલ નંબર, ફી) ને એકસાથે ગ્રુપમાં રાખવા.
struct Student {
  string name;
  int rollNo;
};
