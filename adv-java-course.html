Lesson 1
JDBC આર્કિટેક્ચર & ડ્રાઇવર લોડિંગ
જાવા એપ્લિકેશનને MySQL ડેટાબેઝ સાથે જોડવા માટે JDBC ડ્રાઇવર રજીસ્ટર કરવું.
Class.forName("com.mysql.cj.jdbc.Driver");
Connection con = DriverManager.getConnection(
  "jdbc:mysql://localhost:3306/school", "root", "pass");
📍 મેથડ: DriverManager.getConnection()
JDBC Code

Class.forName("com.mysql.jdbc.Driver");

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. MySQL JDBC Jar ફાઇલ પ્રોજેક્ટમાં એડ કરો.
  2. DriverManager દ્વારા કનેક્શન ઓબ્જેક્ટ મેળવો.
Lesson 2
Statement દ્વારા ડેટા સેવ કરવો (INSERT)
જાવા કોડ દ્વારા ડેટાબેઝ ટેબલમાં નવો રેકોર્ડ ઇન્સર્ટ કરવો.
Statement stmt = con.createStatement();
String q = "INSERT INTO students VALUES(101, 'Amit')";
stmt.executeUpdate(q);
📍 મેથડ: stmt.executeUpdate(query)
SQL Insert

stmt.executeUpdate("INSERT INTO table ...");

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. createStatement બનાવી executeUpdate રન કરો.
Lesson 3
ResultSet દ્વારા ડેટા ફેચ કરવો (SELECT)
ડેટાબેઝમાંથી તમામ વિદ્યાર્થીઓની માહિતી મેળવી કન્સોલ પર પ્રિન્ટ કરવી.
Statement stmt = con.createStatement();
ResultSet rs = stmt.executeQuery("SELECT * FROM students");
while(rs.next()) {
  cout << rs.getString("name");
}
📍 ઓબ્જેક્ટ: ResultSet & rs.next()
SQL Select

ResultSet rs = stmt.executeQuery("SELECT ...");

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. executeQuery વાપરી લૂપ દ્વારા રેકોર્ડસ વાંચો.
Lesson 4
Prepared Statement (સુરક્ષિત ઇનપુટ)
SQL Injection અટકાવવા માટે પ્રિપેર્ડ સ્ટેટમેન્ટ અને પેરામીટર બાઈન્ડિંગ.
PreparedStatement ps = con.prepareStatement(
  "INSERT INTO students VALUES(?, ?)");
ps.setInt(1, 102);
ps.setString(2, "Priya");
ps.executeUpdate();
📍 ક્લાસ: PreparedStatement with '?'
Secure SQL

ps.setString(1, name); ps.executeUpdate();

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. કોડમાં '?' હોલ્ડર વાપરી ડેટા સેટ કરો.

public class MyServlet extends HttpServlet {
  public void doGet(HttpServletRequest req,
    HttpServletResponse res) throws IOException {
    res.getWriter().print("Hello Servlet");
  }
}
📍 ક્લાસ: HttpServlet & doGet/doPost
Servlet

public class LoginServlet extends HttpServlet

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. HttpServlet ક્લાસ ઇનહરિટ કરી doGet ઓવરરાઈડ કરો.

HttpServletRequest & Response
વેબ ફોર્મમાંથી યુઝરનો ડેટા (Parameters) રીસીવ કરવો અને બ્રાઉઝરમાં રિસ્પોન્સ મોકલવો.

Request Data

RequestDispatcher (Forward & Redirect)
એક સર્વલેટમાંથી બીજા સર્વલેટ કે JSP પેજ પર રિક્વેસ્ટ મોકલવી.

📍 મેથડ: rd.forward(req, res)

Lesson 8
સેશન મેનેજમેન્ટ (HttpSession)
યુઝર લોગિન કર્યા પછી આખી વેબસાઇટમાં તેનું નામ યાદ રાખવા માટે Session.
HttpSession session = req.getSession();

// Retrieve: session.getAttribute("user");

Session

session.invalidate(); // Logout

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. getSessionથી સેશન ક્રિએટ કરી ડેટા સ્ટોર કરો.
Lesson 9
JSP બેઝિક્સ & સ્ક્રિપ્ટલેટ ટૅગ્સ
HTML ની અંદર જાવા કોડ લખવા માટે JSP (JavaServer Pages) સ્ક્રિપ્ટલેટ ટૅગ્સ <% %>.
<h1>JSP Page</h1>
<%
  int a = 10, b = 20;
  out.println("Sum: " + (a + b));
%>
📍 ટૅગ: <% %> (Scriptlet Tag)
JSP Tag

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. JSP ફાઇલમાં સ્ક્રિપ્ટલેટ ટૅગ લખી જાવા કોડ રન કરો.
Lesson 10
JSP એબ્જેક્ટ્સ (Implicit Objects)
આપોઆપ ઉપલબ્ધ ઓબ્જેક્ટ્સ (out, request, response, session, application) વાપરવા.
<%

%>
📍 ઓબ્જેક્ટ્સ: out, request, session, response
Implicit Objects

String clientIP = request.getRemoteAddr();

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. Implicit ઓબ્જેક્ટ્સ સીધા જ JSP માં વાપરો.
Lesson 11
JSP એક્સપ્રેશન લેંગ્વેજ (EL - ${expr})
જાવા સ્ક્રિપ્ટલેટ વગર સરળતાથી ડેટા પ્રિન્ટ કરવા માટે ${} એક્સપ્રેશન લેંગ્વેજ.

📍 સિન્ટેક્સ: ${expression}

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ${} સંકેત દ્વારા સેશન કે રિક્વેસ્ટ ડેટા પ્રિન્ટ કરો.
Lesson 12
JSTL ટૅગ લાઈબ્રેરી (JSP Standard Tag Library)

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. JSTL ટેબલ લાઈબ્રેરી ઇમ્પોર્ટ કરી લૂપ ચલાવો.

Advanced 1
હાઇબરનેટ ORM ઇન્ટ્રોડક્શન (Hibernate Framework)
SQL ક્વેરી લખ્યા વગર જાવા ક્લાસને ડેટાબેઝ ટેબલ સાથે મેપિંગ કરવું (ORM).

@Table(name = "students")

}

Hibernate Entity

@Entity public class User { @Id private Long id; }

  1. એનોટેશન્સ દ્વારા જાવા પોજો ક્લાસને એન્ટિટી બનાવો.

SessionFactory & Session (CRUD Operations)
હાઇબરનેટ સેશન દ્વારા ડેટાબેઝમાં રેકોર્ડ સેવ, અપડેટ અને ડીલીટ કરવા.
