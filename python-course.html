Lesson 1
પ્રથમ પ્રોગ્રામ (print statement)
પાયથોનમાં સ્ક્રીન પર લખાણ છાપવા માટે print() ફંક્શનનો ઉપયોગ.
print("નમસ્તે ગુજરાત!")
print("Welcome to Smart Digital School")
📍 સિન્ટેક્સ: print("લખાણ")
Syntax

print("Hello World")

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. એડિટરમાં print() ફંક્શન લખો.
  2. રન કરી આઉટપુટ ચેક કરો.
Lesson 2
વેરિએબલ્સ & ડેટા ટાઇપ્સ (Variables)
નામ, ઉંમર અને ટકાવારી મેમરીમાં સ્ટોર કરવા માટે વેરિએબલ બનાવવા.
name = "રાજેશ"
age = 15
percentage = 88.5
📍 ડેટા ટાઇપ્સ: str, int, float, bool
Variables

x = 10; y = "Python"

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. કોઈપણ ડેટા સીધો વેરિએબલમાં અસાઇન કરો.
Lesson 3
યુઝર ઇનપુટ લેવું (input() function)
કીબોર્ડ દ્વારા યુઝરનું નામ કે માર્ક્સ ઇનપુટ તરીકે મેળવવા.
name = input("તમારું નામ લખો: ")
print("હલો, " + name)
📍 ફંક્શન: input("સંદેશો")
Input

age = int(input("Enter age: "))

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. input ફંક્શન દ્વારા ડેટા સ્વીકારો.
Lesson 4
ગાણિતિક પ્રક્રિયાઓ (Arithmetic Operators)
સરવાળો (+), બાદબાકી (-), ગુણાકાર (*), ભાગાકાર (/) અને ઘાતકીય ગણતરી.
a = 10
b = 5
print(a + b) # 15
print(a * b) # 50
📍 ઓપરેટર્સ: +, -, *, /, %, **
Math

result = 5 ** 2 # 25 (Square)

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. મેથ ઓપરેટર્સ દ્વારા ગણતરી કરો.
Lesson 5
શરતી વિધાનો (if-elif-else)
માર્ક્સના આધારે ઉત્તીર્ણ (Pass) કે ગ્રેડ નક્કી કરવા માટે પાયથોન ઇફ-એલ્સ.
marks = 75
if marks >= 35:
  print("Pass")
else:
  print("Fail")
📍 કીવર્ડ્સ: if, elif, else
Condition

if x > 0: print("Positive")

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ઇન્ડન્ટેશન (સ્પેસ) સાચવી if-else કન્ડિશન લખો.
Lesson 6
ફોર લૂપ (for loop & range)
ચોક્કસ વાર સુધી કોડ રિપીટ કરવા માટે for લૂપ અને range() ફંક્શન.
for i in range(1, 6):
  print(i) # Prints 1 to 5
📍 સિન્ટેક્સ: for i in range():
For Loop

for x in range(5): print(x)

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. range(start, stop) આપી નંબરો પ્રિન્ટ કરો.
Lesson 7
વ્હાઈલ લૂપ (while loop)
શરત સાચી હોય ત્યાં સુધી સતત લૂપ ચલાવવા માટે while સ્ટેટમેન્ટ.
count = 1
while count <= 3:
  print(count)
  count += 1
📍 કીવર્ડ: while condition:
While Loop

while n > 0: n -= 1

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ઇન્ક્રિમેન્ટ કાઉન્ટર સાથે વ્હાઈલ લૂપ ચલાવો.
Lesson 8
લિસ્ટ ડેટા સ્ટ્રક્ચર (Lists)
એક જ વેરિએબલમાં બહુવિધ આઇટમ્સ કે નંબરોનો સંગ્રહ કરવો.
fruits = ["Apple", "Banana", "Mango"]
print(fruits[0]) # Apple
fruits.append("Grapes")
📍 સિન્ટેક્સ: my_list = [item1, item2]
List

numbers = [10, 20, 30]

Lesson 9
ટપલ્સ અને સેટ્સ (Tuples & Sets)
બદલી ન શકાય તેવા ડેટા માટે ટપલ () અને યુનિક આઇટમ્સ માટે સેટ {} વાપરવા.
colors = ("Red", "Green", "Blue") # Tuple

Tuple & Set

Lesson 10
ડિક્શનરી (Dictionaries - Key-Value)
કી અને વેલ્યુ પેર (દા.ત. નામ: અમિત, સ્કોર: ૯૫) ના સ્વરૂપમાં ડેટા સેવ કરવો.
student = {"name": "Amit", "std": 10}

Dictionary

કોડનો પુનઃઉપયોગ કરવા માટે def કીવર્ડ દ્વારા કસ્ટમ ફંક્શન બનાવવા.
def greet(name):
  print("નમસ્તે, " + name)

Function

મોડ્યુલ્સ ઇમ્પોર્ટ કરવા (import math / random)
પાયથોનની પ્રી-બિલ્ટ લાઈબ્રેરીઓ (math, random) નો ઉપયોગ કરવો.
import random
lucky_number = random.randint(1, 10)

📍 કીવર્ડ: import module_name
Import

Advanced 1
ક્લાસ અને ઓબ્જેક્ટ્સ (Classes & Objects)
પાયથોનમાં ઓબ્જેક્ટ ઓરિએન્ટેડ પ્રોગ્રામિંગ (OOPs) નો પાયો અને __init__ કન્સ્ટ્રક્ટર.
class Student:
  def __init__(self, name):
    self.name = name

s1 = Student("અમિત")
📍 કીવર્ડ: class, __init__, self
OOPs Class

class Car: def __init__(self, brand): self.brand = brand

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ક્લાસ બનાવી __init__ દ્વારા ઓબ્જેક્ટ ઇનિશિયલાઈઝ કરો.
Advanced 2
ઇન્હેરીટન્સ (Inheritance - વારસાગત ગુણો)
પેરેન્ટ ક્લાસના ફીચર્સ ચાઇલ્ડ ક્લાસમાં વારસામાં મેળવવા.

📍 સિન્ટેક્સ: class Child(Parent):
Inheritance

class Manager(Employee): pass

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ચાઇલ્ડ ક્લાસમાં પેરેન્ટ ક્લાસ પાસ કરો.
Advanced 3
એક્સેપ્શન હેન્ડલિંગ (try / except)
પ્રોગ્રામ ક્રેશ થયા વગર રન-ટાઇમ એરર્સ (દા.ત. ZeroDivisionError) હેન્ડલ કરવી.
try:
  print(10 / 0)
except ZeroDivisionError:
  print("શૂન્યથી ભાગાકાર અશક્ય છે!")
📍 કીવર્ડ્સ: try, except, finally
Exception

try: ... except Exception as e: print(e)

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. try-except બ્લોક દ્વારા સેફ કોડિંગ કરો.
Advanced 4
ફાઇલ હેન્ડલિંગ (Open, Read, Write Files)
પાયથોન દ્વારા ટેક્સ્ટ ફાઇલ (.txt) ઓપન કરવી, લખાણ લખવું અને વાંચવું.
file = open("note.txt", "w")
file.write("ഹലോ പൈത്തൺ")
file.close()
📍 મોડ્સ: 'r' (Read), 'w' (Write), 'a' (Append)
File I/O

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. with open() સ્ટેટમેન્ટ દ્વારા ફાઇલ મેનેજ કરો.
Advanced 5
લેમ્ડા ફંક્શન્સ (Lambda / Anonymous Functions)
એ જ લીટીમાં ટૂંકા અને અનામિક (Anonymous) ફંક્શન્સ બનાવવા.

print(square(5)) # Outputs 25
📍 કીવર્ડ: lambda arguments: expression
Lambda

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. lambda દ્વારા શોર્ટ ફંક્શન ડિક્લેર કરો.
Advanced 6
લિસ્ટ કોમ્પ્રિહેન્શન (List Comprehension)
માત્ર ૧ લીટીમાં લૂપ ચલાવી નવા લિસ્ટ જનરેટ કરવાની શક્તિશાળી પદ્ધતિ.
squares = [x**2 for x in range(1, 6)]
print(squares) # [1, 4, 9, 16, 25]
📍 શૈલી: [expression for item in iterable]
Comprehension

even = [x for x in range(10) if x % 2 == 0]

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. વન-લાઈન લિસ્ટ કોમ્પ્રિહેન્શન વાપરો.
Advanced 7
JSON ડેટા હેન્ડલિંગ (JSON Module)
પાયથોન ડિક્શનરીને JSON સ્ટ્રિંગમાં કન્વર્ટ કરવી અને API ડેટા પાર્સ કરવો.
import json
data = '{"name": "Amit", "age": 16}'
parsed = json.loads(data)

JSON

પ્રેક્ટિકલ સ્ટેપ્સ:
