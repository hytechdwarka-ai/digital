🌱 Web Dev શું છે? (Architecture)

📌 CSS: રંગ, સ્ટાઇલ અને લેઆઉટ ડિઝાઇન.
📌 JavaScript: લોજિક અને યુઝર ઇન્ટરેક્શન.
📌 Responsive: મોબાઇલ અને લેપટોપ ફ્રેન્ડલી સ્ક્રીન.

Level 1: 12 Foundation Lessons (HTML & CSS)
ટેગ્સ, હેડિંગ્સ, પેરેગ્રાફ, લિંક્સ, ઇમેજ, ટેબલ અને સીએસએસ સ્ટાઇલિંગ.
Lesson 1
HTML બેઝિક સ્ટ્રક્ચર (Basic Boilerplate)
કોઈપણ વેબપેજની શરૂઆત કરવા માટેનું મૂળભૂત એચટીએમએલ માળખું.
<!DOCTYPE html>
<html>
  <head><title>Page</title></head>
  <body> Hello World </body>
</html>
📍 મુખ્ય ટેગ: <html>, <head>, <body>
HTML Tag

<!DOCTYPE html>

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. કોરા નોટપેડમાં બોઇલરપ્લેટ કોડ લખો.
  2. ફાઇલને index.html નામથી સેવ કરો.
Lesson 2
હેડિંગ્સ અને પેરેગ્રાફ्स (H1 to H6 & P)
વેબપેજ પર મોટા શીર્ષકો (H1 થી H6) અને સામાન્ય લખાણ (Paragraph) દર્શાવવા.
<h1>મુખ્ય શીર્ષક (Largest)</h1>
<p>આ સામાન્ય લખાણનો ફકરો છે.</p>
📍 ટેગ્સ: <h1> થી <h6> અને <p>
HTML Tag

<h1>Smart Digital School</h1>

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. H1 માં શાળાનું નામ અને P માં વિગત લખો.
Lesson 3
હાઇપરલિંક્સ (Anchor Tag <a>)
એક વેબપેજ પરથી બીજા પેજ કે ગૂગલ પર જવા માટેની લિંક બનાવવી.
<a href="https://google.com" target="_blank">Google પર જાઓ</a>
📍 એટ્રિબ્યુટ: href="..." target="_blank"
HTML Tag

<a href="url">Link Text</a>

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. href ની અંદર વેબસાઇટનું સરનામું આપો.
Lesson 4
ઇમેજ ઇન્સર્ટ કરવી (Image Tag <img>)
વેબપેજ પર ફોટો કે લોગો પ્રદર્શિત કરવા માટે સોર્સ પાથ આપવો.
<img src="logo.png" alt="School Logo" width="150">
📍 એટ્રિબ્યુટ્સ: src, alt, width, height
HTML Tag

<img src="image.jpg" alt="Photo">

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. src માં ફોટોનું નામ અને alt માં ફોટોની ઓળખ લખો.
Lesson 5
યાદીઓ બનાવવી (Ordered & Unordered Lists)
મુદ્દાઓ દર્શાવવા માટે બુલેટ્સ (<ul>) અથવા નંબર્સ (<ol>) વાપરવા.
<ul>
  <li>HTML</li><li>CSS</li><li>JavaScript</li>
</ul>
📍 ટેગ્સ: <ul>, <ol>, <li>
HTML Tags

<ul><li>Item 1</li></ul>

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. li ટેગની અંદર યાદીના મુદ્દા લખો.
Lesson 6
એચટીએમએલ ટેબલ્સ (<table>)
માર્કશીટ કે ટાઈમટેબલ બનાવવા માટે રો અને કોલમ ગોઠવવા.
<table border="1">
  <tr><th>નામ</th><th>ગુણ</th></tr>
  <tr><td>અમિત</td><td>૮૫</td></tr>
</table>
📍 ટેગ્સ: <table>, <tr>, <th>, <td>
HTML Tags

<table><tr><th>Header</th></tr></table>

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. tr અને td ટેગ દ્વારા ડેટા ભરો.
Lesson 7
સીએસએસ ઇન્ટ્રોડક્શન & કલર્સ (CSS Color & Background)
વેબપેજ પર કલર, બેકગ્રાઉન્ડ અને ફોન્ટ સ્ટાઇલ સેટ કરવી.
body { background-color: #f8fafc; color: #0f172a; }
h1 { color: #ea580c; }
📍 પ્રોપર્ટીઝ: color, background-color
CSS Code

p { color: blue; font-size: 16px; }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. <style> ટેગની અંદર સીએસએસ કોડ લખો.
Lesson 8
બોક્સ મોડેલ (Margin, Padding & Border)
તત્વોની આસપાસ જગ્યા (Margin/Padding) અને બોર્ડર સેટ કરવી.
.box { padding: 20px; margin: 10px; border: 2px solid #cbd5e1; }
📍 પ્રોપર્ટીઝ: margin, padding, border
CSS Code

div { padding: 15px; border: 1px solid black; }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. પેડિંગ અને માર્જિનનો તફાવત સમજો.
Lesson 9
ક્લાસ અને આઈડી સિલેક્ટર્સ (.class & #id)
ચોક્કસ એલિમેન્ટ્સને ડિઝાઇન કરવા માટે Class અને ID નો ઉપયોગ.
.my-card { background: white; border-radius: 8px; }
#main-title { text-align: center; }
📍 સિલેક્ટર્સ: .className અને #idName
CSS Selectors

.btn-primary { background: orange; }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. એચટીએમએલમાં class આપી સીએસએસમાં ડિઝાઇન કરો.
Lesson 10
ફ્લેક્સબોક્સ લેઆઉટ (CSS Flexbox)
એલિમેન્ટ્સને લાઈનમાં ગોઠવવા અને સેન્ટરમાં લાવવા માટે ફ્લેક્સબોક્સ.
.container { display: flex; justify-content: space-between; align-items: center; }
📍 પ્રોપર્ટીઝ: display: flex, justify-content
CSS Flex

display: flex; gap: 10px;

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. કન્ટેનરને flex બનાવી બટનો લાઈનમાં ગોઠવો.
Lesson 11
રેસ્પોન્સિવ મીડિયા ક્વેરીઝ (Media Queries)
મોબાઈલ, ટેબ્લેટ અને લેપટોપ મુજબ અલગ-અલગ ડિઝાઇન સેટ કરવી.
@media (max-width: 600px) { body { font-size: 14px; } }
📍 સિન્ટેક્સ: @media (max-width: ...)
CSS Media Query

@media(max-width: 768px) { .box { width: 100%; } }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. સ્ક્રીન નાની થાય ત્યારે લેઆઉટ બદલવા મીડિયા ક્વેરી લખો.
Lesson 12
એચટીએમએલ ફોર્મ્સ (<form> & Inputs)
લોગિન, રજીસ્ટ્રેશન કે સંપર્ક માટે ઇનપુટ બોક્સ અને સબમિટ બટન બનાવવા.
<form>
  <input type="text" placeholder="નામ લખો">
  <button type="submit">સબમિટ</button>
</form>
📍 ટેગ્સ: <form>, <input>, <button>
HTML Form

<input type="email" placeholder="Email">

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ટાઇપ ટેક્સ્ટ, પાસવર્ડ અને બટન ઉમેરી ફોર્મ બનાવો.
Level 2: 9 Advanced Lessons (JavaScript & DOM)
ચરો, ફંક્શન્સ, ઇવેન્ટ લિસનર્સ, DOM મેનિપ્યુલેશન અને AI વેબ પ્રોમ્પ્ટિંગ.
Advanced 1
જાવાસ્ક્રિપ્ટ વેરીએબલ્સ & એલર્ટ (let, const, alert)
ડેટા સ્ટોર કરવા માટે વેરીએબલ્સ બનાવવા અને સ્ક્રીન પર પોપ-અપ મેસેજ આપવો.
let studentName = "અમિત";
alert("સ્વાગત છે " + studentName);
📍 કીવર્ડ્સ: let, const, alert()
JS Code

let score = 95; console.log(score);

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. <script> ટેગમાં વેરીએબલ ડિક્લેર કરી એલર્ટ ચેક કરો.
Advanced 2
DOM મેનિપ્યુલેશન (getElementById)
જાવાસ્ક્રિપ્ટ દ્વારા વેબપેજનું લખાણ કે ડિઝાઇન ડાયનેમિકલી બદલવી.
document.getElementById("title").innerText = "નવું ટાઇટલ!";
📍 મેથડ: document.getElementById()
JS DOM

document.getElementById("demo").style.color = "red";

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. આઈડી દ્વારા એલિમેન્ટને સિલેક્ટ કરી ટેક્સ્ટ બદલો.
Advanced 3
ફંક્શન્સ અને ઇવેન્ટ્સ (onclick Event)
બટન ક્લિક કરવાથી કોઈ ચોક્કસ ફંક્શન અથવા ટાસ્ક રન કરવું.
<button onclick="myFunction()">Click</button>
function myFunction() { alert('Clicked!'); }
📍 એટ્રિબ્યુટ: onclick="..."
JS Function

function calculateSum(a, b) { return a + b; }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. બટન પર onclick ઇવેન્ટ જોડો.
Advanced 4
શરતી નિવેદનો (if / else Conditions)
ગુણ અથવા ઉંમરના આધારે પાસ/ફેલ કે એલિજિબિલિટી ચેક કરવી.
if (marks >= 35) { alert("Pass"); } else { alert("Fail"); }
📍 કીવર્ડ્સ: if, else if, else
JS Logic

if (age >= 18) { canVote = true; }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. if-else કન્ડિશન મૂકી પરિણામ ચકાસો.
Advanced 5
જવાબ અને લૂપ્સ (For & While Loops)
એક જ કામ વારંવાર પુનરાવર્તિત કરવા માટે લૂપનો ઉપયોગ કરવો.
for (let i = 1; i <= 5; i++) { console.log(i); }
📍 કીવર્ડ: for loop, while loop
JS Loop

for (let i=0; i<arr.length; i++) { ... }

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ફોર લૂપ ચલાવી નંબર્સ પ્રિન્ટ કરો.
Advanced 6
એરે અને ઓબ્જેક્ટ્સ (Arrays & Objects)
ઘણા બધા ડેટાને એકસાથે સ્ટોર કરવા માટે એરે અને કી-વેલ્યુ માટે ઓબ્જેક્ટ.
let subjects = ["Math", "Science", "Computer"];
let student = { name: "Raj", std: 10 };
📍 ડેટા સ્ટ્રક્ચર: [], {}
JS Array/Object

let user = { id: 101, active: true };

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ઓબ્જેક્ટ પ્રોપર્ટી એક્સેસ કરવાનું શીખો.
Advanced 7
લોકલ સ્ટોરેજ (localStorage Data Save)
બ્રાઉઝરમાં પાયાનો ડેટા કાયમ માટે (પેજ રિફ્રેશ થયા પછી પણ) સેવ રાખવો.
localStorage.setItem("username", "Amit");
let user = localStorage.getItem("username");
📍 મેથડ્સ: setItem(), getItem()
Storage API

localStorage.setItem("theme", "dark");

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. લોકલ સ્ટોરેજમાં ડેટા સેવ કરી ગેટ કરો.
Advanced 8
એપીઆઈ ફેચ (Fetch API & JSON)
ઇન્ટરનેટ પરથી લાઈવ ડેટા (વેધર, ન્યૂઝ વગેરે) જાવાસ્ક્રિપ્ટ દ્વારા મેળવવા.
fetch('https://api.example.com/data')
  .then(res => res.json())
  .then(data => console.log(data));
📍 ફંક્શન: fetch() .then()
API Fetch

fetch(url).then(response => response.json())

પ્રેક્ટિકલ સ્ટેપ્સ:
  1. ફેચ એપીઆઈ દ્વારા ડેટા લોડ કરો.
